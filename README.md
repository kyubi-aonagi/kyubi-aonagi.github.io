# Kyubi Aonagi

Trang giới thiệu vtuber Kyubi Aonagi — lore, model showcase và playlist nhạc nền.

- `index.html` — trang chính: lore, hồ sơ nhân vật, hành trình tỉnh giấc
- `showcase.html` — trang model showcase kiểu poster reveal
- `playlist.html` — đĩa nhạc xoay phát playlist của Aonagi

## Chạy thử ở máy

Mở trực tiếp `index.html` bằng trình duyệt, hoặc chạy một server tĩnh bất kỳ trong thư mục này.

## Deploy

Trang này host qua GitHub Pages, build thẳng từ nhánh `main`.
